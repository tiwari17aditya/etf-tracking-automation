# Stock Market Study Curriculum: From Beginner to Advanced

Welcome to the comprehensive, structured financial curriculum. This library is designed to take you from market fundamentals to quantitative factor models and options mechanics.

Each module includes conceptual breakdowns, mathematical formulas, and instructions on how to use Antigravity's live MCP tools (`stock-analyst`) to test concepts with real data.

---

## 🚀 How to Study with Antigravity

Whenever you are studying any topic in these guides:
1. **Ask for Live Verification**: E.g., *"Antigravity, explain ROCE using the formula in Chapter 2, and then calculate it for TCS using live MCP financials."*
2. **Ask for Multi-Timeframe Scans**: E.g., *"Antigravity, check the RSI-14 and 50 EMA on GOLDBEES and tell me if it meets the Smart Dip accumulation criteria."*
3. **Run Backtests**: E.g., *"Use DuckDB SQL tool to simulate a 14-period RSI dip strategy on the last 6 months of daily candles."*
